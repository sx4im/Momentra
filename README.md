# ✨ Momentra ✨

> 📸 A beautiful photo gallery built with HTML, CSS, and JavaScript

## 🌟 Features

- 🖼️ Responsive masonry layout that looks amazing on all devices
- 🌓 Dark and light theme support
- ✨ Smooth animations and transitions
- 🔍 Elegant lightbox for immersive viewing
- 🏷️ Smart filtering and tagging system
- 📱 Touch and keyboard navigation
- 🚀 Fast loading with lazy load support
- 🎨 Easily customizable with simple options

## 📥 Installation

```
git clone https://github.com/yourusername/momentra.git
cd momentra
```

## 🚀 Quick Start

1. Add your photos to the `images` folder
2. Open `index.html` in your browser
3. Enjoy your beautiful gallery!

## ⚙️ Configuration

Customize Momentra by editing the options in `js/config.js`

## 🎨 Customization

Change colors, fonts and animations with CSS variables in `css/style.css`
